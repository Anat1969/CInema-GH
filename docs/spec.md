# קולנועע — אפיון אפליקציה

## חזון
אפליקציה חוויתית לחקירת תפיסות עולם דרך עיני ארבעה תפקידים קולנועיים.
לא קורס קולנוע. לא מאגר סרטים.
חוויה של גילוי — מה הסרט האהוב שלי אומר על הדרך שבה אני רואה את העולם.

## שם
**קולנועע** — קולנוע + נוע. תנועה דרך קולנוע.

## קהל יעד
אנשים שאוהבים סרטים ורוצים להבין אותם עמוק יותר.
לא נדרש ידע מקדים. נדרשת סקרנות.

---

## ארכיטקטורת מסכים

### 1. כניסה (Entrance Hall)
- מסך פתיחה: משפט אחד — "מה הסרט האחרון שלא הצלחת לשכוח?"
- כניסה: Google Auth ישיר, בלי טפסים
- מיד אחרי — בחירת נקודת כניסה: אחד מארבעת החדרים

### 2. ארבעה חדרי תפקידים
כל חדר: שאלות ליבה, חקירה מונחית עם הקולנוען (ה-AI), תובנה מסכמת.

| חדר | תפקיד | שאלת הליבה |
|-----|--------|-------------|
| 🎬 חדר הבמאי | הבמאי בוחר | מה בחרת לא לראות? |
| 💡 חדר הצלם | הצלם קורא אור | מה האור מסתיר? |
| ✍️ חדר התסריטאי | התסריטאי שואל למה | מה הדמות לא מסוגלת לומר? |
| 🎵 חדר המוזיקאי | המוזיקאי מרגיש | מה הגוף הרגיש לפני שהמוח הבין? |

### 3. חדר הגילוי
אחרי ארבעת החדרים: הקולנוען מסכם את תפיסת העולם של המשתמש ונותן לה שם.
פורמט: 4 משפטים (אחד לכל תפקיד) + שם התפיסה.

### 4. אולפן היצירה
בניית קונספט סרט מתוך התפיסה שנחשפה:
1. משפט אחד — הרעיון
2. שאלת במאי — מה לא יראה?
3. שאלת צלם — מה יוסתר באור?
4. שאלת תסריטאי — מה הדמות לא תגיד?
5. שאלת מוזיקאי — מה הגוף ירגיש לפני שהמוח יבין?
6. תוצאה: "פריים ראשון" + "צליל ראשון"

### 5. ארכיון הגילויים
שמירת תפיסות עולם שנחשפו ברשימה אישית.
אפשרות שיתוף: "שתף את תפיסת העולם שלך"

## ניווט
- סרגל עליון קבוע: שם האפליקציה (קישור לבית) + כפתור תפריט
- חדרים נגישים תמיד מהסרגל — לא נדרש לסיים חדר כדי לעבור לאחר
- מצב "בחקירה" vs מצב "ב-AI" — מעבר חלק ללא רענון דף

## מערכת עיצוב

### עקרון
שחור, לבן ואוויר. צבע רק כשיש לו תפקיד.

### פלטה
- רקע: לבן `#FFFFFF`
- טקסט ראשי: שחור `#0A0A0A`
- גוון חדר הבמאי: `#1A1A2E` (כחול לילה עמוק)
- גוון חדר הצלם: `#2D1B00` (ענבר כהה)
- גוון חדר התסריטאי: `#0D2818` (ירוק יער כהה)
- גוון חדר המוזיקאי: `#1A0A2E` (סגול עמוק)
- הקולנוען: `#111111` עם גופן איטלקי

### טיפוגרפיה
- כותרות: גופן סריף, גדול, מרווח
- טקסט AI (הקולנוען): איטלקי, מרווח-שורה גדול
- תשובות משתמש: רגיל, בהיר יותר
- ממשק: ללא קישוטים — פונקציה בלבד

### כפתורים
- מרובעים, ללא עיגולים
- לחיצים: צל קל, בלי מסגרת
- מצב hover: שינוי רקע, לא שינוי גודל

### כניסה לחדר
אנימציית מעבר: fade-in של שניה אחת.
הטקסט הראשון שמופיע: שאלת הליבה של החדר, במרכז, גדול.

## דאטה מודל (Supabase)

### טבלאות

```sql
users
  id uuid primary key
  email text
  created_at timestamp

sessions
  id uuid primary key
  user_id uuid references users
  started_at timestamp
  completed_rooms text[] -- ['director', 'cinematographer', 'screenwriter', 'musician']

room_conversations
  id uuid primary key
  session_id uuid references sessions
  room text -- 'director' | 'cinematographer' | 'screenwriter' | 'musician'
  messages jsonb -- [{role, content, timestamp}]
  worldview_insight text -- תובנה מסכמת שהקולנוען ייצר
  created_at timestamp

worldview_profiles
  id uuid primary key
  user_id uuid references users
  session_id uuid references sessions
  director_insight text
  cinematographer_insight text
  screenwriter_insight text
  musician_insight text
  worldview_name text -- השם שהקולנוען נתן לתפיסה
  film_concept jsonb -- {idea, frame, sound}
  created_at timestamp
  is_shared boolean default false
```

- **Frontend**: React + TypeScript + Tailwind CSS + shadcn/ui
- **Backend**: Supabase (Auth + PostgreSQL + Edge Functions)
- **AI**: Claude claude-sonnet-4-6 דרך Supabase Edge Function
